# Data Package

Aggregated, disclosure-safe data for the paper "Exploring Execution-Form Boundaries in Brain–Cerebellum Collaboration".

## Contents

- `models.md` — models, roles, sizes, runtimes
- `tasks.md` — task descriptions (single-step rounds + multi-step scenarios); task materials are not published
- `results/round1-2-majority.csv` — A/B/C majority and per-run results, two rounds
- `results/tier-gradient.csv` — three local tiers
- `results/light-task-subset.csv` — light-task subset pass rates
- `results/g-series-summary.csv` — G1–G3 quality/time/token
- `results/g4-summary.csv` — G4 counter-example
- `results/v-series.csv` — V0–V4 execution-form isolation
- `results/g4-token-baseline.csv` — token baseline used in cost analysis
- `results/cost-price-snapshot.csv` — fixed price snapshot (standard rates, USD per million tokens; snapshot date and vendor pages in paper)
- `results/cost-scenario-results.csv` — brain-only vs collaboration cost scenarios

## Boundaries

- Aggregated results only; raw session logs, execution scripts, prompts with embedded materials, and task materials are not published.
- Price snapshot is fixed at paper time; vendor prices vary with peak/off-peak and promotions.
